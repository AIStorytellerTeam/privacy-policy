# Документы AI Storyteller

Публичные юридические документы приложения **AI Storyteller / Fairytale Gardens**
(`com.unil.aistoryteller`), опубликованные через GitHub Pages.

| Документ | Адрес |
|---|---|
| Политика конфиденциальности | `/privacy/` · `/privacy/en/` |
| Пользовательское соглашение | `/terms/` · `/terms/en/` |
| Удаление аккаунта и данных | `/delete-account/` · `/delete-account/en/` |

Эти адреса указываются в Google Play Console (политика конфиденциальности и
раздел «Безопасность данных → Удаление аккаунта») и в самом приложении,
в настройках. Менять их после публикации нежелательно: ссылки уже разойдутся
по карточке магазина и по установленным приложениям.

Полные адреса после включения Pages:
`https://aistorytellerteam.github.io/privacy-policy/privacy/` и так далее.

## Как это устроено

Страницы собираются GitHub Pages из markdown-файлов в корне. Оформление —
единственный шаблон `_layouts/doc.html` со встроенным CSS: готовую тему не
подключали намеренно, чтобы страницы не тянули посторонние шрифты и хорошо
читались с телефона. Адрес каждой страницы задан полем `permalink` в шапке
файла, поэтому переименование файла адрес не ломает.

## Как обновить текст

**Markdown-файлы в корне генерируются автоматически — правит их скрипт, а не
человек.** Источник правды один: папка `legal/` в основном репозитории
приложения. Там же текст показывается внутри приложения, офлайн, — поэтому
правка «только на сайте» неизбежно разъехалась бы с тем, что видит пользователь.

Порядок такой:

1. В основном репозитории правите `legal/*.md`.
2. Там же выполняете `node scripts/build-legal.js` — он обновит и страницы
   здесь, и встроенный в приложение текст (`src/legal/legalContent.ts`).
3. Здесь коммитите и пушите в `main` — GitHub Pages пересоберёт сайт за
   минуту-две.

Руками в этом репозитории редактируют только `_config.yml`, `_layouts/doc.html`,
`index.md` и этот файл — их скрипт не трогает.

При изменении существенных условий меняйте дату вступления в силу в начале
документа и сообщайте пользователям — это требование и соглашения, и GDPR.

## Свой домен

Если подключите собственный домен, обнулите `baseurl` в `_config.yml`
(`baseurl: ""`) и поправьте `url`. Пока сайт лежит в подпапке репозитория,
`baseurl` обязателен: без него внутренние ссылки ведут на корень github.io.
